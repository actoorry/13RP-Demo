## 一、物理现实层（1-5RP）— 数据底座

> **策略**：以采购集成的 ERP 为核心数据底座（选型待定，赤龙 ERP 等开源方案仅作参考），集成周边工业软件生态。不重复造业务轮子，只做数据打通、清洗、标准化，向上层仿真层供给干净实时数据。

### 技术组合

| 编号 | 维度 | 核心职责 | 集成方案 |
|:---:|------|---------|---------|
| **1RP** | 基础资源 | 清点家底：产能、库存、资金、运力 | **ERP（选型待定）+ WMS + MES** — ERP 统一企业存量业务数据（赤龙 ERP 等开源方案仅作参考） |
| **2RP** | 流程协同 | 链条跑通：订单→采购→生产→交付 | **低代码 BPM + EDI** — 端到端业务流程数字化建模与跨系统编排 |
| **3RP** | 组织权责 | 谁说了算：权限、合规、跨国法规 | **IAM 权限体系 + 区块链存证** — 多层权限 + 操作不可篡改审计 |
| **4RP** | 绩效监控 | 看得见问题：实时看板、秒级报警 | **Apache Flink 流计算 + BI (Tableau)** — 关键指标实时刷新 ≤ 1 秒 |
| **5RP** | 优化调度 | 快速纠偏：动态调拨、改期排产 | **运筹调度引擎 (Gurobi)** — 将上层最优方案翻译为可执行指令 |

### ERP 选型原则（赤龙 ERP 仅作参考）

```
ERP 选型待定，赤龙 ERP 等开源方案仅作参考。选型评估维度：
  开源免费       → 无授权费，可私有化部署，可深度定制
  模块完整       → 财务/供应链/制造/HR 等模块覆盖 1-3RP 核心需求
  数据主权       → 企业完全掌控数据，不被商业 ERP 厂商锁定
  API 开放性     → RESTful API + 数据库直连，便于 13RP 数据管道对接
  （商业 ERP 亦可，按企业现状、集成成本与数据开放度综合评估）

周边集成（不重复造轮子）：
  WMS + MES       → 仓储和制造执行层面补充
  Flink + Tableau → 实时计算与可视化
  Gurobi          → 运筹学优化求解
  IAM + 区块链    → 权限与合规审计
```

### 设计原则

```
✗ 不做：重复实现 ERP / WMS / MES 已有的业务逻辑
✓ 只做：①全部打通  ②把数据干净地喂给 6-10 层
```

1-5 层是"数据入口"，不是"业务中台"。所有存量系统的数据经 ODS→CDM→ADS 标准化后，以统一 Schema 向上供给仿真层。

## 二、平行模拟层（6-10RP）— 核心护城河

> **策略**：核心自研。基于 ERP 提供的干净数据，自研数字孪生、多目标寻优、博弈对抗仿真算法构建核心护城河。这是 SAP、Oracle 做不了的差异化能力。

### 技术组合

| 编号 | 维度 | 核心职责 | 技术方案 |
|:---:|------|---------|---------|
| **6RP** | 数字孪生 | 把现实搬进电脑，建高保真镜像 | **P0: Three.js WebGL**（轻量 Demo）/ **P1+: Unity 工业版**（高保真渲染）— 工厂级孪生场景，不用停工就能做实验 |
| **7RP** | 方案推演 | 输入 X，自动跑出因果链 | **AnyLogic 离散事件仿真引擎** — 封装自研调度逻辑，蒙特卡洛 1000 次随机扰动，输出三维预测曲面（成本/碳排/交期） |
| **8RP** | 多目标寻优 | 成本/碳排/交期/质量四维拉满 | **自研 NSGA-III 进化算法** — 寻找帕累托前沿，输出 5+ 非劣解，每个附带完整资源需求清单 |
| **9RP** | 博弈对抗 | 用 AI 模拟对手/政府/国际组织的反应 | **自研 RLlib 多智能体博弈框架** — 内置多套预设对手策略，每个方案跑对抗并输出综合胜率 |
| **10RP** | 实验迭代 | 100 个平行世界同时跑，筛出胜率 TOP3 | **Kubernetes 容器化调度 + MLflow 实验管理** — 批量跑平行宇宙场景，漏斗筛选最优方案 |

### 数据漏斗

```
1000 条初始方案 → 8RP 筛选 50 个帕累托解 → 9RP 对抗后剩 10 个 → 10RP 输出 TOP3
```

### 为什么这是护城河

| 竞品 | 能做到的 | 做不到的 |
|------|---------|---------|
| SAP Joule | 事后报表 + AI 问答 | 平行模拟、多宇宙并行推演 |
| Oracle AI | 流程自动化 | 博弈对抗、帕累托多目标寻优 |
| o9 / Cosmo Tech | 仿真+优化（接近 6-8RP） | 无博弈对抗（9RP）、无并行迭代（10RP） |

**任何一个单点（仿真/寻优/博弈）都有工具，但基于开源 ERP 数据底座、把三层（孪生→寻优→博弈→迭代）串成闭环的，市场上不存在。**

## 三、愿景驱动层（11-13RP）— 顶层大脑

> **策略**：大模型 Agent 体系，可插拔设计。给仿真层定决策方向，解决传统系统只能事后统计、无法承接顶层战略的痛点。

### Agent 架构

| 编号 | Agent 名称 | 核心职责 | 技术支撑 |
|:---:|-----------|---------|---------|
| **13RP** | **愿景意图 Agent** | CEO 自然语言战略拆解器：把"零碳、全球化"等口述战略拆解为量化目标、约束条件、里程碑 | 国产大模型 / GPT / Claude 可插拔 + RAG 知识库 + 人工确认 |
| **12RP** | **虚实映射 Agent** | 全网舆情、用户行为量化转决策参数：线上舆论/社群情绪 → 量化指标 → 输入时空轴 | 舆情大模型 + 用户行为埋点 |
| **11RP** | **宏观时空 Agent** | 拉取 3-10 年行业、国际宏观数据做长期约束：地缘政治、气候、人口等变量纳入模拟参数空间 | 国际数据库 + 时间序列预测 |

### 示例：CEO 愿景 → 执行指令

```
输入：CEO 口述 "我们要在 2030 年前成为零碳产业园"

13RP 愿景意图 Agent：
  拆解 → 碳排降 40% + 成本增加 ≤ 15% + 不影响交付周期
  输出 → 量化目标体系 + 约束条件 + 里程碑节点

12RP 虚实映射 Agent：
  拉入 → 碳税政策趋势、国际舆论压力指数、ESG 评级影响

11RP 宏观时空 Agent：
  拉入 → 未来 10 年碳交易价格预测、清洁能源成本曲线

        ↓ 三组约束汇入 6-10 层

6-10RP 平行模拟：
  跑 100 轮仿真（不同能源组合 × 不同产线布局 × 不同供应商策略）

        ↓ 最优方案降维

5RP 输出执行指令：
  "本周签 A 国土地意向书，Q3 启动光伏屋顶招标……"
```

### 为什么 LLM 只是"可插拔"的

- 11-13 层不训练自己的基础模型，只做调用和编排
- 模型抽象层支持切换：GPT-4 ↔ Claude ↔ 国产大模型
- 核心价值在 Agent 的**拆解逻辑**和**RAG 知识库**，不在模型本身
- 11-13 层是"方向盘"，6-10 层是"发动机"——没有 13RP，6-10 层是一台没有方向盘的高性能发动机

## 四、数据底层配套

### 三层数据仓库

```
外部数据源（MES / ERP / API / IoT / 舆情）
              ↓
    ┌─────────────────┐
    │   ODS 原始层     │  ← 原始数据，不做清洗，保留完整历史
    └────────┬────────┘
              ↓
    ┌─────────────────┐
    │   CDM 标准化层   │  ← 统一"时间/空间/实体"三维度，清洗标准化
    └────────┬────────┘
              ↓
    ┌─────────────────┐
    │   ADS 应用层     │  ← 为各 RP 层提供定制数据视图
    └────────┬────────┘
              ↓
     各 RP 层消费 → 结果反馈回 ODS 层
```

### 全链路数据闭环

```
愿景层输入（战略目标 + 约束条件）
       ↓
模拟层仿真计算（千条方案推演 + 寻优 + 博弈）
       ↓
现实层执行下发（5 条指令 → 采购单/排程单/物流单）
       ↓
业务数据回流（执行结果、偏差、异常）
       ↓
模型自动校准迭代（仿真精度持续提升）
       ↓
（回到愿景层，下一轮决策）
```

**闭环周期**：月度迭代 → 周度迭代 → 实时动态寻优（随数据积累逐步加速）

### 跨层通信格式

| 数据流 | 格式 | 说明 |
|--------|------|------|
| 1-5RP → 6RP | Protobuf | 孪生状态快照，类型安全、高效序列化 |
| 6RP → 7RP | Protobuf | 仿真参数与初始状态 |
| 8RP → 9RP | JSON | 帕累托方案集，人类可读便于调试 |
| 10RP → 5RP | 结构化数据 | TOP3 方案及可执行指令 |
| 11-13RP → 6RP | JSON | 战略目标拆解后的约束参数 |

## 五、分层投入与优先级

| 层级 | 策略 | P0 投入 | P1-P3 投入 | 关键风险 |
|------|------|:---:|:---:|------|
| **1-5RP** | ERP（选型待定）+ 周边集成 | 低（模拟数据替代） | 中（真实系统对接） | ERP 对接复杂度 |
| **6-8RP** | 🔒 核心自研 | 中（Demo 简化版） | 🔴 高（算法攻坚） | NSGA-III 4 目标收敛速度 |
| **9-10RP** | 自研 + 开源 | 无（P0 不涉及） | 高（RL+K8s） | 多智能体训练不稳定 |
| **11-13RP** | 合作调用 | 无（P0 不涉及） | 高（LLM 幻觉控制） | 大模型输出不可控 |
| **数据底层** | 自研 | 低（手工 JSON） | 中（自动化管道） | 数据质量与一致性 |
