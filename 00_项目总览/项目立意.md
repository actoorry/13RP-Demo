# 项目立意 — 13RP 博宇宙决策操作系统

> **日期**：2026 年 7 月 30 日  
> **状态**：正式立项

---

## 一、这是什么

**13RP** 是一个十三维决策操作系统。它不替代 ERP，而是在 ERP 之上构建"平行模拟层"——把现实世界搬进数字空间，在虚拟世界里预演千条路径，再把最优解降维为今天下午 3 点的一条采购指令。

**一句话**：传统 ERP 是后视镜，13RP 是能看见 13 条岔路的前挡风。

---

## 二、为什么是现在

三个窗口同时打开：

| 窗口 | 数据 |
|------|------|
| **市场窗口** | 全球数字孪生市场 2026 年 420 亿美元，CAGR 41.9%。92% 的企业项目卡在 3D 可视化阶段，能做"预判决策"的系统几乎空白 |
| **技术窗口** | LLM Agent 在供应链推演、多目标优化、博弈对抗领域的学术验证 2026 年密集爆发（ACL/AAMAS/IEEE）。NSGA-III、RLlib、AnyLogic 等工具链成熟可用 |
| **竞争窗口** | SAP Joule、Oracle AI 本质是"AI 插件"——在旧架构上叠加。从架构层设计平行模拟的系统，市场上尚不存在 |

**窗口期判断**：2-3 年。头部厂商的收购（西门子 100 亿美元收购 Altair）和 NVIDIA Cosmos 等平台在加速行业成熟。

## 三、与已有方案的差异

| 对比维度 | 传统 ERP + AI | 数字孪生平台 | 13RP |
|---------|:-----------:|:----------:|:---:|
| 核心范式 | 记录→报表 | 可视化→监控 | **模拟→决策→执行** |
| 能否回答"如果…会怎样" | ✗ | ◐ | ✓ |
| 能否并行跑 N 个方案 | ✗ | ✗ | ✓ |
| 能否对抗博弈 | ✗ | ✗ | ✓ |
| 能否把 CEO 愿景拆解为执行指令 | ✗ | ✗ | ✓  |
| 输出精度 | 图表 | 仪表盘 | 今天下午 3 点的 5 条指令 |

**核心差异**：别人在"看"，13RP 在"算"。别人给图表，13RP 给行动指令。

## 四、技术路径

```
物理现实层(1-5RP)  → 资源·流程·权责·监控·调度    [采购集成：ERP（选型待定）+ 周边]
平行模拟层(6-10RP) → 孪生·推演·寻优·博弈·迭代    [核心自研：NSGA-III/AnyLogic/RLlib]
愿景驱动层(11-13RP)→ 时空轴·虚实映射·愿景意图     [合作调用：GPT-4/Claude]
```

- 1-5 层：不重复造轮子，调通存量系统
- 6-10 层：**全部核心自研**，这是护城河
- 11-13 层：对接大模型生态，保持可插拔

## 七、项目立意的底层逻辑

```
现象：企业面对供应链中断、成本波动、地缘风险时，
     决策方式仍是"开会+Excel+拍脑袋"

根因：现有系统（ERP/MES/WMS）的设计假设是
     "世界是确定的、信息是充分的、对手是不动的"

13RP 的答案：
     世界是不确定的 → 平行模拟预演千条路径
     信息是不充分的 → 博弈对抗补全对手视角
     对手是会动的   → 实验迭代持续更新最优解
     老板有愿景     → 愿景驱动层自动拆解为目标-约束

结果：从"事后看报表"到"事前算方案"，
     从"拍脑袋决策"到"概率驱动的决策"，
     从"部门局部最优"到"企业全局最优"。
```
