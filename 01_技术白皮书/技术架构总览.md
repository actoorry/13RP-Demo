---

## 技术策略：成熟采购 + 核心自研 + 前沿合作

```
┌─────────────────────────────────────────────┐
│  11-13RP  愿景驱动层                         │
│  策略：合作调用                               │
│  技术：GPT-4 / Claude / 国产大模型             │
├─────────────────────────────────────────────┤
│  9-10RP  博弈对抗 + 实验迭代                  │
│  策略：自研 + 开源                            │
│  技术：RLlib / Kubernetes / MLflow           │
├─────────────────────────────────────────────┤
│  6-8RP  数字孪生 + 方案推演 + 多目标寻优       │
│  策略：核心自研 ← 这是壁垒                     │
│  技术：NSGA-III / AnyLogic / 自研仿真引擎      │
├─────────────────────────────────────────────┤
│  1-5RP  物理现实层                            │
│  策略：采购集成                               │
│  技术：SAP / Unity / Gurobi / Tableau         │
└─────────────────────────────────────────────┘
```

## 各层投入策略

| 层级 | 策略 | 原因 |
|------|------|------|
| 1-5RP | 采购集成 | 成熟市场，不重复造轮子 |
| 6-8RP | **核心自研** | 算法壁垒，差异化核心 |
| 9-10RP | 自研+开源 | 前沿技术，灵活迭代 |
| 11-13RP | 合作调用 | 依赖大模型生态，可插拔 |

## 研发团队规模

| 组别 | 人数 | 职责 |
|------|:---:|------|
| 核心算法组 | 8-10 人 | 6-10 层算法研发 |
| 集成组 | 5 人 | 1-5 层系统打通与数据接入 |
| 前端/运维 | 4 人 | 看板与孪生界面 + DevOps |

## 技术选型（P0 阶段）

| 用途 | 选型 | 授权方式 |
|------|------|---------|
| 数字孪生建模 | Unity 工业版 | 年费 6 万 |
| 仿真引擎 | AnyLogic 专业版 | 年费 8 万（教育折扣可降至 5-6 万） |
| 多目标寻优 | 自研（NSGA-III） | 核心壁垒 |
| 实时看板 | Flink + BI | 开源/采购 |
| 云基础设施 | 阿里云（4×16C/32G + 1×GPU/A10） | 按量付费 |
| 容器编排 | Kubernetes | 开源 |
