# 02 — 非功能需求、数据架构与接口

> **来源**：《痴人白日梦话二》第 15-17 页

---

## 一、非功能需求

| 类型 | 要求 |
|------|------|
| **性能** | 单次仿真（含 1000 次随机扰动）< 5 分钟；单次寻优 < 30 分钟 |
| **可用性** | 核心服务可用性 ≥ 99.5%；数据每日备份；支持按角色分级权限 |
| **扩展性** | 所有层级模块可独立部署；支持后续接入外部数据源/算法模型 |
| **安全** | 数据传输全链路加密；区块链存证数据不可篡改；私有化部署选项 |
| **可观测性** | 全链路日志追踪；Prometheus 监控；Grafana 告警；关键操作审计日志 |

## 二、数据架构

```
外部数据源（MES/ERP/API）
        ↓
    ODS 层 ← 原始数据，不做清洗
        ↓
    CDM 层 ← 清洗后标准化（统一"时间/空间/实体"维度）
        ↓
    ADS 层 ← 为各 RP 层提供特定数据视图
        ↓
  各 RP 层消费 → 结果存储 → 反馈回 ODS 层（闭环）
```

## 三、接口清单

### 对外接口

| 接口 | 格式 | 用途 |
|------|------|------|
| 方案结果导出 API | JSON / Excel | 对外交付决策结果 |
| 孪生场景嵌入 API | iframe | 嵌入客户自有系统 |

### 对内接口

| 数据流 | 格式 | 说明 |
|--------|------|------|
| 1-5RP → 6RP | Protobuf | 孪生状态快照，类型安全、高效序列化 |
| 6RP → 7RP | Protobuf | 仿真参数与初始状态 |
| 8RP → 9RP | JSON | 帕累托方案集 |
| 10RP → 5RP | 结构化数据 | TOP3 方案及执行指令 |
| 11-13RP → 6RP | JSON | 战略目标拆解后的约束参数 |

## 五、P0 阶段非功能简化清单

> P0 Demo 阶段仅要求以下简化指标（详见 `03_P0阶段_MVP/Demo实施计划书.md` 第七章），上表完整非功能需求为 P1+ 目标。

| 类别 | P0 要求 | 说明 |
|------|---------|------|
| 性能 | 看板刷新 < 1s；推演动画 ≤ 120s；Three.js 首屏 < 3s | 预计算 + 动画，非真实计算 |
| 稳定性 | 完整演示连续 5 遍无崩溃；断网 10s 自动重连 | 见实施计划书 7.3 |
| 部署 | Docker Compose 一键启动；阿里云 + 本地双环境 | 4C/16G ECS |
| 安全 | 演示环境最小暴露；仅模拟数据，无真实业务数据 | P0 全模拟 |
| 可观测性 | 后端关键状态日志 + 前端控制台无报错 | 简化为日志即可 |

P0 不要求：99.5% 可用性 SLA、区块链存证、全链路加密、Prometheus/Grafana 监控体系——均为 P1+ 目标。
