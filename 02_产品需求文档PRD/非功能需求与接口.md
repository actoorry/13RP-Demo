# 02 — 非功能需求、数据架构与接口

> **来源**：《痴人白日梦话二》第 15-17 页

---

## 一、非功能需求

| 类型 | 要求 |
|------|------|
| **性能** | 单次仿真（含 1000 次随机扰动）< 5 分钟；单次寻优 < 30 分钟 |
| **可用性** | 核心服务可用性 ≥ 99.5%；数据每日备份；支持按角色分级权限 |
| **扩展性** | 所有层级模块可独立部署；支持后续接入外部数据源/算法模型 |
| **安全** | 数据传输全链路加密；区块链存证数据不可篡改；私有化部署选项 |
| **可观测性** | 全链路日志追踪；Prometheus 监控；Grafana 告警；关键操作审计日志 |

## 二、数据架构

```
外部数据源（MES/ERP/API）
        ↓
    ODS 层 ← 原始数据，不做清洗
        ↓
    CDM 层 ← 清洗后标准化（统一"时间/空间/实体"维度）
        ↓
    ADS 层 ← 为各 RP 层提供特定数据视图
        ↓
  各 RP 层消费 → 结果存储 → 反馈回 ODS 层（闭环）
```

## 三、接口清单

### 对外接口

| 接口 | 格式 | 用途 |
|------|------|------|
| 方案结果导出 API | JSON / Excel | 对外交付决策结果 |
| 孪生场景嵌入 API | iframe | 嵌入客户自有系统 |

### 对内接口

| 数据流 | 格式 | 说明 |
|--------|------|------|
| 6RP → 7RP | Protobuf | 孪生状态快照 |
| 8RP → 9RP | JSON | 帕累托方案集 |
| 10RP → 5RP | 结构化数据 | TOP3 方案及执行指令 |
