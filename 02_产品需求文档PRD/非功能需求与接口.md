## 〇、功能需求（P0 功能复现版）

> **依据**：`04_参考资料/功能清单.md`（博宇四方管理端 SaaS 管理系统 V1.0，36 张截图 OCR）
> **原则**：**复现功能而非二次开发**——从零实现、功能对齐、数据模型按 13RP 分层重新建模。
> **范围分层**：P0 核心五模块全量复现；CMS 后置 P1；系统管理仅占位（参考截图未覆盖，待补充需求）。

### 0.1 公司架构（组织与权限）— 对应 3RP 组织权责

| 子模块 | 功能需求 | 验收要点 |
|--------|---------|---------|
| 机构管理 | 机构树增删改、排序、批量删除；示例：博宇集团（总裁办/幸福盟事业部/世贸项目部） | 树形展示、级联删除校验 |
| 人员管理 | 增加用户、批量导出、批量删除；字段：头像/账号/姓名/手机/部门/职位；按姓名/关键词/状态筛选 | 导出 Excel；状态筛选 |
| 角色管理 | 新增角色、批量删除、授权；字段：角色名称/排序；示例角色：系统管理/组长/组员 | 菜单级授权生效（按钮级权限） |

### 0.2 商品管理（商品数据字典）— 对应 1RP 基础资源

| 子模块 | 功能需求 | 验收要点 |
|--------|---------|---------|
| 频道管理 | 新建频道；字段：频道名称/创建人/创建时间/状态（待使用/使用中）；示例：石油化工/稀土/办公设备 | 状态流转 |
| 品类管理 | 添加品类/子品类/编辑/删除；所属频道/名称/排序/是否显示；**支持三级分类** | 三级树 + 级联删除校验 |
| 属性管理 | 添加/编辑/删除/详情；字段：属性名称/关联品类/参数值/属性值/是否启用/排序；示例：品牌/产地/规格/材质/牌号（稀土：镝/铒铝/铕） | 属性-品类关联 |
| 规则管理 | 添加规则；字段：关联品类/属性名/属性值/发布时间 | CRUD |
| 单位管理 | 添加单位；字段：关联品类/单位名称/是否启用；示例：公斤、吨 | CRUD |
| 单位换算管理 | 添加换算规则；字段：单位名称/转换单位/是否启用；示例：1000 公斤→吨 | 换算逻辑 |
| 合同要素管理 | 新增要素/详情；字段：要素名称/所属频道/结算方式/运费承担/供方备注/付款方式/可供数量 | CRUD |
| 合同要素项管理 | 新增要素项/编辑/删除；示例项：装货地址/卸货地址/品名/装货时间/卸货时间/结算方式/预算价格/重量/供方数量/报价 | **5RP 指令字段来源** |

### 0.3 数据统计 — 对应 4RP 绩效监控

| 子模块 | 功能需求 | 验收要点 |
|--------|---------|---------|
| 数据总览 | 用户总计/今日新增/新增企业用户/新增个人用户；用户总数统计图（企业/个人按月趋势） | 统计口径正确 |
| 用户统计/明细 | 时间筛选 + 用户姓名/企业/手机号/客户所属/ERP 同步状态搜索；ERP 三维口径：未查到总数/已找到未主动填写/信息不一致；字段含 ERP 公司名称/所属组织/负责人/注册渠道；支持导出 | 口径与功能清单一致 |
| 数据统计明细 | 统计维度（总计/按员工）；品类数（总/一/二/三级）；属性数/属性值/规则发布次数/完整度（如 85.5%）；企业完整度/Web 链接/供求发布数；内容统计（简介/领域/新闻/招聘/案例）；累计 vs 昨日；月度趋势图 | 完整度计算正确 |
| 企业信息录入 | 生态企业库：搜索（名称/负责人/分类/手机号/录入时间）；字段：负责人/企业名称/三级分类/属性/属性值/联系人；P0 模拟 ≥1000 条 | 搜索/筛选/分页 |

## 一、非功能需求

| 类型 | 要求 |
|------|------|
| **性能** | 单次仿真（含 1000 次随机扰动）< 5 分钟；单次寻优 < 30 分钟 |
| **可用性** | 核心服务可用性 ≥ 99.5%；数据每日备份；支持按角色分级权限 |
| **扩展性** | 所有层级模块可独立部署；支持后续接入外部数据源/算法模型 |
| **安全** | 数据传输全链路加密；区块链存证数据不可篡改；私有化部署选项 |
| **可观测性** | 全链路日志追踪；Prometheus 监控；Grafana 告警；关键操作审计日志 |

## 二、数据架构

```
外部数据源（MES/ERP/API）
        ↓
    ODS 层 ← 原始数据，不做清洗
        ↓
    CDM 层 ← 清洗后标准化（统一"时间/空间/实体"维度）
        ↓
    ADS 层 ← 为各 RP 层提供特定数据视图
        ↓
  各 RP 层消费 → 结果存储 → 反馈回 ODS 层（闭环）
```

## 三、接口清单

### 对外接口

| 接口 | 格式 | 用途 |
|------|------|------|
| 方案结果导出 API | JSON / Excel | 对外交付决策结果 |
| 孪生场景嵌入 API | iframe | 嵌入客户自有系统 |

### 对内接口

| 数据流 | 格式 | 说明 |
|--------|------|------|
| 1-5RP → 6RP | Protobuf | 孪生状态快照，类型安全、高效序列化 |
| 6RP → 7RP | Protobuf | 仿真参数与初始状态 |
| 8RP → 9RP | JSON | 帕累托方案集 |
| 10RP → 5RP | 结构化数据 | TOP3 方案及执行指令 |
| 11-13RP → 6RP | JSON | 战略目标拆解后的约束参数 |

## 五、P0 阶段非功能简化清单

> P0 Demo 阶段仅要求以下简化指标（详见 `03_P0阶段_MVP/Demo实施计划书.md` 第七章），上表完整非功能需求为 P1+ 目标。

| 类别 | P0 要求 | 说明 |
|------|---------|------|
| 性能 | 看板刷新 < 1s；推演动画 ≤ 120s；列表页加载 < 3s（千条级） | 预计算 + 动画，非真实计算 |
| 稳定性 | 完整演示连续 5 遍无崩溃；断网 10s 自动重连 | 见实施计划书 7.3 |
| 部署 | Docker Compose 一键启动；阿里云 + 本地双环境 | 4C/16G ECS |
| 安全 | 演示环境最小暴露；仅模拟数据，无真实业务数据；JWT 登录 + RBAC 权限 | P0 全模拟 + 真实权限 |
| 可观测性 | 后端关键状态日志 + 前端控制台无报错 + 演示事件审计（demo_event_log） | 简化为日志即可 |

P0 不要求：99.5% 可用性 SLA、区块链存证、全链路加密、Prometheus/Grafana 监控体系——均为 P1+ 目标。
