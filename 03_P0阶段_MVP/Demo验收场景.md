# 03 — P0 Demo 验收场景

> **来源**：《痴人白日梦话二》第 18-23 页  
> **定位**：3 个月后向管理层/投资人/种子客户的 15 分钟闭门演示

---

## 案例背景

| 维度 | 内容 |
|------|------|
| **企业代称** | 博宇制造 |
| **行业** | 新能源车电驱系统 |
| **布局** | 中国、越南、墨西哥三地工厂 |
| **突发事件** | 墨西哥工厂突发停电（预计持续 5 天） |

**核心问题**：减产、调货、还是空运补料？

---

## Demo 前准备工作

1. 接入中国/越南/墨西哥三厂的在制品、库存、订单、物流时效数据（支持模拟数据源）
2. 在 6RP 中构建三个工厂的数字孪生，标注"产线 A""成品仓 B""港口 C"三个关键节点
3. 预设三种行动预案：①越南增产+海运补货 ②中国空运关键部件 ③墨西哥减产+延长交期补偿

---

## 演示流程（15 分钟，5 步）

### 第 1 步（2 分钟）：问题抛入

| 操作 | 点击"模拟：墨西哥工厂停电 5 天" |
|------|------|
| **系统反应** | 4RP 看板墨西哥工厂产能利用率从 92% → 0%，红色报警闪烁 |
| **讲者旁白** | "墨西哥工厂是北美市场核心供应节点。停电 5 天，下周 3000 台电驱系统面临违约风险。" |

### 第 2 步（3 分钟）：系统自动推演

| 操作 | 7RP 自动触发，后台静默运行 |
|------|------|
| **系统反应** | 6RP 孪生显示三厂物流链路动态闪烁；屏幕显示"推演中…已跑完 342 条路径"；弹出 3 条推荐路径及三维指标雷达图 |
| **讲者旁白** | "传统做法是打电话、开会、拍脑袋。13RP 的做法是：5 分钟内在平行宇宙里把能走的路全部走一遍。" |

### 第 3 步（3 分钟）：多目标寻优

| 操作 | 勾选偏好"本次优先保交付，成本其次" |
|------|------|
| **系统反应** | 8RP 对三条路径重新排序，将"空运方案"推到第一位；展开执行细节 |
| **讲者旁白** | "您只需告诉系统'这次我保交付'，它就自动把资源清单列好。" |

### 第 4 步（3 分钟）：博弈对抗

| 操作 | 点击"加入博弈层" |
|------|------|
| **系统反应** | 9RP 加载"竞争对手同步涨价"和"墨西哥政府可能免关税应急"两个对抗因素；"空运方案"胜率从 78% 降至 61%，"海运补货"胜率反超至 69% |
| **讲者旁白** | "竞争对手涨价会冲击成本优势，免关税让海运成本进一步降低。13RP 把看不见的变量也拉进来一起算。" |

### 第 5 步（4 分钟）：降维输出

| 操作 | 点击"执行" |
|------|------|
| **系统反应** | 自动生成 5 条待办指令 |

最终输出的 5 条指令：

1. 向国航预订货舱（CA123，今晚 22:00 起飞）
2. 向越南工厂下发增产指令
3. 向接插件供应商发出紧急采购单
4. 向墨西哥海关提交应急通关预申请
5. 向北美客户发送交期确认函

> **讲者金句**："别人家的系统告诉您'发生了什么'，13RP 告诉您'现在该做什么，以及为什么这么做是算出来的最优解'。"

---

## 验收标准

| 验收项 | 标准 |
|--------|------|
| 数据接入 | 至少 2 个外部数据源实时接入，看板刷新 < 1 秒 |
| 孪生建模 | 30 分钟内完成 3 个工厂的简化孪生建模 |
| 推演速度 | 单次推演 < 5 分钟（含 1000 次随机扰动） |
| 寻优输出 | 输出至少 3 个非劣解，附带资源需求清单 |
| 降维输出 | 最终输出精确到"今天下午 3 点的 5 条指令" |
| 用户体验 | 全程零代码操作，纯点击/勾选完成决策链 |

---

## Demo 冲刺计划（3 个月倒排）

| 时间节点 | 里程碑 | 交付物 |
|:------:|------|------|
| 第 1 个月末 | 数据打通 | 至少 2 个数据源 API 成功拉取数据，存入 ODS 层 |
| 第 2 个月中 | 孪生+看板上线 | 6RP 孪生场景可展示，4RP 看板实时刷新 |
| 第 2 个月末 | 推演+寻优 Demo 版 | 7RP 单变量推演可跑通，8RP 输出帕累托解（3+个） |
| 第 3 个月中 | 博弈+降维联调 | 9RP 预设策略加载，5RP 指令生成联调 |
| 第 3 个月末 | **Demo Day** | 完整 15 分钟演示流程跑通，无卡顿、无崩溃 |
