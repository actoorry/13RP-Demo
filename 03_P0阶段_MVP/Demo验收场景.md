# 03 — P0 Demo 验收场景（V0.3 功能复现版）

> **来源**：`04_参考资料/功能清单.md`（博宇四方管理端 SaaS 管理系统 V1.0，36 张界面截图 OCR 整理）+《痴人白日梦话二》
> **版本**：V0.3（功能复现 + 国内场景决策演示）
> **定位**：3 个月后向管理层/投资人/种子客户交付的**可运行功能复现系统** + 15 分钟国内场景决策演示

---

## 案例背景

| 维度 | 内容 |
|------|------|
| **企业代称** | 博宇集团（博宇四方 SaaS 管理端） |
| **业务** | 大宗商品 B2B 平台（频道示例：石油化工、稀土、办公设备等） |
| **决策演示场景** | 第 9 号台风"海燕"登陆华东，**宁波舟山港 / 上海港封港 5 天**，某品类（稀土/石油化工）供应中断，订单交付告急 |
| **突发事件** | 台风封港导致物流中断（预计持续 5 天） |

**核心问题**：改港转运、空运救急、还是启用备选供应商？

---

## Demo 前准备工作

1. **功能复现系统就绪**（对应功能清单，逐模块可操作）：
   - 公司架构：机构管理（树）、人员管理、角色管理（含授权）
   - 商品管理：频道、品类（三级）、属性、规则、单位、单位换算、合同要素、合同要素项
   - 数据统计：数据总览、用户统计/明细（含 ERP 同步状态）、数据统计明细（品类/属性/规则/企业信息完整度）、企业信息录入（生态企业库，模拟 ≥1000 条数据）
   - CRM：线索、客户、线索池、客户公海、自定义字段设置
   - 运营管理：客户运营（用户管理）、认证管理、共享数据、多名头关联
2. **决策演示数据就绪**：国内物流网络（上海港/宁波舟山港/青岛港/天津港 + 苏州/上海仓库节点）、预计算推演路径 342 条、帕累托方案 3 组、博弈胜率矩阵、基于合同要素的指令模板
3. **模拟数据源就绪**：订单、库存、物流时效、港口状态（支持模拟数据源，P0 以模拟器实现外部数据源协议）

> **CMS 与系统管理模块**：CMS 9 个子模块（首页装修/栏目/文章/生态等）后置 P1；系统管理模块因参考截图未覆盖，P0 仅做系统级配置占位（待补充需求后再细化）。

## 演示流程（15 分钟，5 步）

### 第 1 步（2 分钟）：问题抛入

| 操作 | 进入"数据统计→数据总览"，点击"模拟：台风致宁波舟山港封港 5 天" |
|------|------|
| **系统反应** | 4RP 看板：订单交付率从 96% 下降、物流异常报警闪烁；商品管理侧该品类（如稀土·镝）库存预警；物流网络图宁波/上海节点变红 |
| **讲者旁白** | "台风封港 5 天，下周 3000 吨稀土面临违约风险。传统做法是打电话、开紧急会议、拍脑袋——我们先看看 13RP 怎么做。" |

### 第 2 步（3 分钟）：系统自动推演

| 操作 | 点击"启动推演"（事件注入后系统自动弹出确认），7RP 后台静默运行 |
|------|------|
| **系统反应** | 物流网络图各节点/线路动态闪烁；屏幕显示"推演中…已跑完 342 条路径"；弹出 3 条推荐路径及三维指标雷达图（成本/碳排/交期/风险） |
| **讲者旁白** | "传统做法是开会拍脑袋。13RP 的做法是：5 分钟内在平行宇宙里把能走的路全部走一遍。" |

### 第 3 步（3 分钟）：多目标寻优

| 操作 | 勾选偏好"本次优先保交付，成本其次" |
|------|------|
| **系统反应** | 8RP 对三条路径重新排序，将"空运/快速路径"推到第一位；展开执行细节（含合同要素字段） |
| **讲者旁白** | "您只需告诉系统'这次我保交付'，它就自动把方案排好。" |

### 第 4 步（3 分钟）：博弈对抗

| 操作 | 点击"加入博弈层" |
|------|------|
| **系统反应** | 9RP 加载"港口拥堵加剧""竞争对手抢订舱位""台风路径延长""客户同意延期"四个对抗因素；空运方案胜率下降、备选供应商方案反超 |
| **讲者旁白** | "港口拥堵会让空运也堵在路上，竞争对手抢舱位推高成本。13RP 把看不见的变量也拉进来一起算。" |

### 第 5 步（4 分钟）：降维输出

| 操作 | 点击"执行"（承接第 4 步已确认方案） |
|------|------|
| **系统反应** | 自动生成 5 条待办指令（基于合同要素 schema：装货港/卸货港/品名/数量/时间/负责人/失效条件） |

最终输出的 5 条指令：

1. 向船运公司预订宁波→青岛转港舱位（本周内装船，卸货港：青岛前湾港）
2. 向仓储方下发转运指令（品名：稀土·镝，数量：1200 吨，装货时间/卸货时间）
3. 向备选供应商发出紧急采购单（品名/预算价格/重量/供方数量）
4. 向海关提交转关通关预申请（装货地址/卸货地址）
5. 向客户发送交期确认函（结算方式/付款方式/预计交付时间）

> **讲者金句**："别人家的系统告诉您'发生了什么'，13RP 告诉您'现在该做什么，以及为什么这么做是算出来的最优解'。每条指令都有'什么条件下会失效'——可证伪性。"

## 验收标准

### A. 功能复现验收（新增，对齐 `04_参考资料/功能清单.md`）

| 模块 | 子模块 | 验收标准 |
|------|--------|---------|
| 公司架构 | 机构/人员/角色 | 机构树（博宇集团/总裁办/幸福盟事业部/世贸项目部）增删改；人员 CRUD + 批量导出/删除 + 状态筛选；角色 CRUD + 授权（菜单级权限生效） |
| 商品管理 | 频道/品类/属性/规则/单位/单位换算/合同要素/要素项 | 频道增删改（待使用/使用中）；品类三级树；属性关联品类（品牌/产地/规格/材质/牌号）；规则发布；单位 + 单位换算（1000 公斤→吨）；合同要素 + 要素项（装货地址/卸货地址/品名/装货时间/结算方式/预算价格/重量/供方数量/报价） |
| 数据统计 | 数据总览/用户统计/统计明细/企业信息录入 | 用户统计图（企业/个人按月趋势）；ERP 同步三维统计口径；品类/属性/规则/企业信息完整度统计；生态企业库 ≥1000 条（含三级分类/属性/属性值），支持搜索 |
| CRM | 线索/客户/线索池/公海/自定义字段 | 线索+客户 CRUD + 视图切换（全部/我负责/下属/已转化/我关注）；线索池 + 公海规则；自定义字段按模块维护 |
| 运营管理 | 客户运营/认证管理/共享数据/多名头关联 | 用户管理（搜索/导出/冻结）；企业认证审核（通过/拒绝）；共享数据开关；多名头关联（集团名称/关联名头/进度） |
| 通用能力 | 查询/重置/导出/分页/行操作 | 列表页通用操作齐全；分页 10 条/页 + 跳页；导出 Excel 可用 |

> **验收口径**：以上按功能清单逐项核对（建议对照 36 张截图逐屏走查）。P0 以模拟数据源验收；P1 起对接真实 ERP/博宇四方 SaaS 数据。

### B. 决策演示验收

| 验收项 | 标准 |
|--------|------|
| 事件注入 | 台风封港事件注入后，看板订单交付率下降 + 物流报警 < 0.5s 触发 |
| 推演速度 | 推演动画 ≤ 120s（预计算回放），展示 342 条路径、1000 次随机扰动 |
| 寻优输出 | 输出至少 3 个非劣解，附带资源需求清单（含合同要素字段） |
| 博弈对抗 | 4 个对抗因素可勾选，胜率实时变化（预计算），方案排序更新 |
| 降维输出 | 最终输出 5 条指令，精确到"今天下午 3 点前"，含负责人/截止时间/失效条件 |
| 用户体验 | 全程零代码操作，纯点击/勾选完成决策链 |

### C. 性能与稳定性验收

| 指标 | 目标 | 测试方法 |
|------|:---:|---------|
| 看板数据刷新延迟 | < 1 秒 | Chrome DevTools Network 面板 |
