## 一、系统框架（公共布局）

| 区域 | 功能 | 说明 |
|------|------|------|
| 顶部栏 | 公司选择 | 切换管理公司（如：沈阳博宇会幸福实业有限公司） |
| 顶部栏 | 平台选择 | 切换业务平台（如：全球发展） |
| 侧边栏 | 一级导航 | 公司架构 / CRM / 商品管理 / 系统管理 / CMS / 运营管理 / 数据统计 |
| 通用操作 | 查询 / 重置 / 导出 / 分页 | 列表页通用：关键字搜索、条件筛选、重置、数据导出（Excel）、分页（10条/页、跳页） |
| 列表操作 | 详情 / 编辑 / 删除 / 启用(停用) / 预览 / 装修 | 各列表页通用行级操作 |

## 二、公司架构（组织与权限）

### 1. 机构管理
- 新增 / 批量删除机构
- 机构名称、排序、编辑、删除
- 机构树示例：博宇集团（总裁办、幸福盟事业部、世贸项目部…）

### 2. 人员管理
- 增加用户、批量导出、批量删除
- 字段：头像、账号、姓名、手机、部门、职位
- 职位示例：数据录入
- 支持按姓名/关键词、用户状态筛选

### 3. 角色管理
- 新增角色、批量删除
- 字段：角色名称、排序、编辑、删除、授权
- 角色示例：系统管理、CMS 权限、组长权限、组员权限

---

## 三、CRM（客户关系管理）

### 1. 线索管理
- 新建线索
- 显示视图：全部线索 / 我负责的线索 / 下属负责的线索 / 已转化的线索 / 我关注的线索
- 高级筛选
- 字段：线索名称、线索来源、企业类型、手机、电话、邮箱、地址、客户行业、客户级别、下次联系时间、备注、最后跟进时间

### 2. 客户管理
- 新建客户
- 显示视图：全部客户 / 我负责的客户 / 下属负责的客户 / 我关注的客户
- 高级筛选
- 字段：客户名称、客户来源、企业类型、手机、电话、邮箱、地址、客户行业、客户级别、下次联系时间、备注、最后跟进时间

### 3. 线索池管理
- 搜索（名称/手机/电话）、高级筛选
- 系统默认线索池、线索池规则

### 4. 客户公海（公海管理）
- 搜索（名称/手机/电话）、高级筛选
- 系统默认公海、公海规则

### 5. 自定义字段设置
- 按模块维护自定义字段：线索管理、客户管理、联系人管理、产品管理
- 显示模块图标、模块、更新时间、编辑操作

---

## 四、商品管理（商品/品类/数据字典）

### 1. 频道信息管理
- 新建所属频道
- 字段：频道名称、创建人、创建时间、状态（待使用/使用中）
- 示例频道：石油化工、火电业脑技术、办公设备等

### 2. 品类管理
- 添加品类、添加子品类、编辑、删除
- 字段：所属频道、品类名称、排序、是否显示
- 支持多级分类：一级/二级/三级分类
- 示例：办公设备-二级分类、特种设备-二级分类、仪器仪表、农业机械、房地产（三级）、信软技术服务（三级）、装饰装修、管理服务、文体娱乐等

### 3. 属性管理
- 添加属性、编辑、删除、详情
- 字段：属性名称、关联品类、参数值、属性值、是否启用、排序
- 示例属性：品牌/产地、规格、材质、牌号等（如稀土系列：镝、铒铝、铕）

### 4. 规则管理
- 添加规则
- 字段：关联品类、属性名、属性值、发布时间

### 5. 单位管理
- 添加单位
- 字段：关联品类、单位名称、是否启用
- 示例：公斤、JUn（吨）等

### 6. 单位换算管理
- 添加单位换算规则
- 字段：单位名称、转换单位名称、是否启用
- 示例：1000 公斤 → 吨

### 7. 生态管理
- 新建生态关联
- 字段：品类名称、生态名称、创建人、创建时间

### 8. 生态管理管理
- 新建文章生态
- 字段：文章生态名称、创建人、创建时间、编辑时间、使用中
- 示例生态：供求信息发布、企业信息发布、信息发布、底端菜单、金刚区、注册、知识产权、法律声明、隐私政策、交通资讯等

### 9. 合同要素管理
- 新增要素、详情
- 字段：要素名称、所属频道、创建人、创建时间、结算方式、运费承担、供方备注、付款方式、可供数量等

### 10. 合同要素项管理
- 新增要素项、编辑、删除
- 字段：要素项名称、创建人、创建时间、修改时间
- 示例要素项：装货地址、卸货地址、品名、装货时间、卸货时间、结算方式、预算价格、重量、供方数量、报价

## 五、CMS（内容管理）

### 1. 首页管理
- 新建首页
- 字段：首页名称、语言（中文等）、创建人/时间、修改人/时间、发布状态（已发布/未发布）
- 行操作：预览、装修、更多
- 页面装修支持：金刚区、底端菜单等模块

### 2. 频道分区管理
- 新增频道分区
- 字段：首页名称、分区名称、状态、频道按钮数量、创建人/时间、修改人/时间
- 示例分区：金刚1、金刚2

### 3. 图片池管理
- 新建图片池
- 字段：图片池 ID、图片池名称、图片数量、创建人/时间、修改人/时间
- 示例：广告位轮播图、帮助中心、关于我们、金刚区图片

### 4. 栏目管理
- 新建栏目
- 字段：栏目名称、排序、文章数、创建时间、启用/停用
- 示例栏目：数据协同伙伴、帮助中心、企业简介、企业荣誉、新闻中心、业务领域、企业招聘、党群建设、关于我们

### 5. 筛选组件管理
- 新建筛选组件
- 字段：筛选组件 ID、筛选组件名称、语言、创建人/时间、修改人/时间、发布状态
- 行操作：预览、装修、更多
- 示例：操作指南、合规与法律-文章组件

### 6. 文章管理
- 新建文章
- 字段：文章名称、栏目名称、创建人、浏览量、创建时间、启用/停用
- 示例：中国电力企业联合会、中国连锁经营协会、中国商业联合会、中国人力资源开发研究会、中华全国律师协会、中国农业国际合作促进会、中国光伏行业协会、中国能源研究会、国际咨询工程师联合会等（数据协同伙伴文章）

### 7. 文章生态管理
- 新建文章生态
- 字段：文章生态名称、创建人、创建时间、编辑时间

### 8. 文章生态关联管理
- 新建文章生态关联
- 字段：文章名称、文章生态名称、创建人、创建时间、编辑时间

### 9. 子文章管理
- 新建子文章
- 字段：子文章名称、所属文章、关联品类、文章生态、创建人、浏览量、排序、创建时间、是否启用
- 示例：中东版/美国版/欧盟版隐私政策、项目需求、项目供应、我的、消息、工作台、企业注册

---

## 六、运营管理

### 1. 客户运营（用户管理）
- 创建用户、导出
- 搜索：用户姓名/企业、手机号、分类（渠道）、用户类型
- 字段：用户名称、注册手机号、是否实名、公司名称、企业是否认证、状态（使用/冻结）、注册时间、用户类型（企业用户等）、注册渠道（微信小程序 Wechat_mini / Android / iPhone）

### 2. 认证管理
- 企业认证审核：详情、审核通过、审核拒绝
- 字段：用户名称、企业名称、认证状态（待认证）、认证时间

### 3. 共享数据
- 共享数据开关（开启后所有平台可见数据）
- 说明文案：当共享数据开启时，所有平台都可以看到数据

### 4. 多名头关联
- 新增多名头关联
- 字段：集团名称（对外展示名称）、关联名头企业名称、创建人、创建时间、进度（处理中/已启用）
- 示例：沈阳有色金属加工有限公司 / 銮麟金属贸易（沈阳）有限公司

## 七、数据统计

### 1. 数据总览（数据概览）
- 用户统计：用户总计、今日新增用户、新增企业用户、新增个人用户
- 用户总数统计图（企业用户 / 个人用户，按月份趋势）
- 新增用户统计图（新增用户 / 新增企业用户 / 新增个人用户）

### 2. 用户统计 / 用户明细
- 搜索：选择时间（开始/结束日期）、用户姓名/企业、手机号、客户所属、ERP 同步状态
- 统计维度：ERP 未查到的用户总数、ERP 已找到未主动填写企业信息、企业用户与 ERP 企业信息不同
- 字段：用户姓名、注册手机号、是否实名、公司名称、ERP 公司名称、企业是否认证、所属组织、负责人、注册时间、注册渠道
- 支持导出

### 3. 数据统计明细（多维度统计）
- **选择统计维度**：总计 / 按员工
- **品类统计**：品类数（总）、一级品类、二级品类、三级品类
- **属性 & 规则统计**：属性数（总）、属性、属性值、规则发布次数、规则内容详情条数、规则总计、完整度（如 85.5%）
- **企业信息统计**：企业完整度、Web 链接录入、供应信息发布数、需求信息发布数
- **内容统计**：企业简介、业务领域、新闻中心、企业文化、企业招聘、经典案例、供应商企业维护、客户企业维护
- 每项均含累计数据 / 昨日数据对照
- 数据统计趋势图（按月：品类、属性、规则、企业信息）

### 4. 企业信息录入（生态企业库）
- 搜索：企业名称、负责人、分类、手机号、录入时间
- 字段：负责人（姓名）、企业名称、一级分类、二级分类、三级分类、属性、属性值、联系人、操作
- 示例企业：威海恒邦矿冶发展有限公司、广州新城市投资控股集团有限公司、南京朗诗物业管理有限公司等（约 18540 条）

## 八、功能模块汇总统计

| 一级模块 | 子模块数量 | 功能要点 |
|:--------:|:--------:|---------|
| 公司架构 | 3 | 机构管理、人员管理、角色管理（组织 + 账号 + 权限） |
| CRM | 5 | 线索、客户、线索池、客户公海、自定义字段（销售全流程） |
| 商品管理 | 10 | 频道、品类（三级）、属性、规则、单位、单位换算、生态、合同要素等（商品数据字典） |
| 系统管理 | — | 系统级配置 |
| CMS | 9 | 首页装修、频道分区、图片池、栏目、筛选组件、文章、文章生态、子文章（内容全链路） |
| 运营管理 | 4 | 客户运营（用户）、认证审核、共享数据、多名头关联 |
| 数据统计 | 3+ | 数据总览、用户统计、多维度统计明细（品类/属性/规则/企业信息） |

> **注**：共 7 大一级模块、30+ 二级子模块；部分页面（如系统管理详情、装修编辑器、新建弹窗表单）截图未覆盖，功能以实际系统为准。
