# 竞品与参考产品调研 — 13RP 决策操作系统

> **日期**：2026 年 7 月 30 日
> **调研范围**：全球范围内与 13RP 存在功能重叠或架构相似的决策/仿真/优化/数字孪生产品
> **前置阅读**：`00_项目总览/13RP总纲.md`、`技术可行性与市场环境评估.md`

## 一、调研框架

13RP 的核心能力栈由四个维度构成，没有任何单一产品完全覆盖：

```
        博弈对抗 (9RP)
             ▲
多目标寻优 (8RP) ←→ 推演仿真 (6-7RP)
             ▲
    数字孪生 (6RP) + 数据集成 (1-5RP)
             ▲
     LLM/Agent 决策交互 (11-13RP)
```

竞品调研按"**与 13RP 能力重叠度**"分为四个梯队，从近到远排列。

## 二、第一梯队：最接近 13RP 愿景的产品

### 2.1 o9 Solutions — Digital Brain 平台

| 维度 | 评估 |
|------|------|
| **定位** | AI 驱动的供应链规划与决策平台 |
| **成立** | 2009 年，总部美国达拉斯 |
| **融资/估值** | 2024 年估值约 37 亿美元 |
| **核心架构** | Enterprise Knowledge Graph (EKG) 作为数字孪生底座 |

**与 13RP 重叠的能力：**

| 13RP 维度 | o9 对应能力 | 差距分析 |
|-----------|------------|---------|
| **6RP 数字孪生** | EKG 构建供应链网络数字孪生，含 Tier 1-3 供应商可见性 | ✅ 成熟，但粒度偏供应链网络，不做工厂级物理仿真 |
| **7RP 方案推演** | What-if 场景模拟，AI Agent 自动跑假设情景 | ✅ 成熟，但重点在规划层面（S&OP），不涉及离散事件仿真 |
| **8RP 多目标寻优** | 启发式/线性规划/MIP 多求解器，平衡服务-成本-库存 | ✅ 成熟，但在 4+ 目标帕累托寻优上不如专用算法 |
| **9RP 博弈对抗** | ❌ 无博弈对抗能力 | ❌ 缺失。不做对手/政府/市场多方博弈 |
| **11-13RP 愿景驱动** | GenAI 知识助手 + LLM 嵌入，自然语言查询与场景规划 | ⚠️ 部分。能做 NL→分析，不做 CEO 愿景→目标拆解 |

**对 13RP 的启示：**
- EKG（企业知识图谱）是数字孪生的优秀架构范式，13RP 可借鉴"本体驱动"的数据模型设计
- o9 的"Post-Game Analyzer"（事后复盘分析器）与 13RP 的"可证伪性"设计原则一致
- o9 证明了"数字孪生 + AI 规划 + 多目标优化"在商业上是可行的，年价值创造数亿美元

**对 13RP 的威胁等级：🟡 中低** — o9 深耕供应链规划，不做工厂级仿真和博弈，与 13RP 定位有本质差异。

### 2.2 Cosmo Tech — AI Simulation 平台

| 维度 | 评估 |
|------|------|
| **定位** | 企业级 AI 仿真 + 规范性优化（Prescriptive Optimization） |
| **成立** | 2010 年，法国里昂 |
| **融资** | 约 2424 万美元 |
| **特色** | 被 Gartner 评为"供应链智能仿真领域最值得击败的公司" |

**与 13RP 重叠的能力：**

| 13RP 维度 | Cosmo Tech 对应能力 | 差距分析 |
|-----------|-------------------|---------|
| **6RP 数字孪生** | 360° 整体仿真孪生（Holistic Simulation Twin） | ✅ 强项。不只做几何模型，做企业动态互联建模 |
| **7RP 方案推演** | 数千个自动 What-if 场景并行运行 | ✅ 强项。自动扫描脆弱性（Vulnerability Scan） |
| **8RP 多目标寻优** | 规范性优化：同时平衡成本-服务-韧性-碳排 | ✅ 强项。输出带分步执行指令的优化行动方案 |
| **9RP 博弈对抗** | ❌ 无博弈对抗 | ❌ 缺失 |
| **11-13RP 愿景驱动** | AI-Simulation Copilot（GenAI 虚拟助手，自然语言交互） | ⚠️ 有 LLM 交互但不做愿景拆解 |

**13RP 最值得借鉴的点：**
- "对从未发生过的情境做预测"的能力 — 不依赖历史模式，基于业务规则建模
- 结果"可解释、可审计" — 与 13RP 可证伪性原则高度一致
- SAP IBP 集成 — 验证了"仿真引擎 + ERP"的互补定位可行
- Michelin（34 家工厂）、RTE（法国电网）等重量级客户 — 证明大企业愿意为仿真决策买单

**对 13RP 的威胁等级：🟡 中低** — 最像 13RP 中层的产品，但规模小、缺博弈层、缺愿景层。

### 2.3 ToolsGroup — Decion™ 平台（2026 年 5 月发布）

| 维度 | 评估 |
|------|------|
| **定位** | 下一代 Agentic AI 供应链平台 |
| **核心概念** | 从"预测可能发生什么"转向"持续将决策引向正确的业务结果" |

**与 13RP 的重叠：**

| 能力 | 描述 | 与 13RP 对比 |
|------|------|------------|
| **Agentic Digital Twin** | 持续感知和适应变化的供应链状况 | ≈ 6RP 概念，但偏库存/需求孪生 |
| **概率决策智能** | 在数百万个可能未来中建模不确定性 | ≈ 7RP 蒙特卡洛推演 |
| **多目标规范性优化** | 同时平衡服务/成本/利润/风险 | ≈ 8RP 多目标寻优 |
| **概率场景智能** | Agentic AI 创建风险-收益场景 | ≈ 9RP 轻量版（但非博弈对抗） |
| **Agentic Execution** | 在人控护栏内自主决策执行 | ≈ 5RP 调度 |

**关键差异：** ToolsGroup 聚焦于库存优化和需求规划，不做工厂级数字孪生和博弈对抗。

**对 13RP 的威胁等级：🟡 中低** — 理念相似（AI + 仿真 + 决策闭环），但赛道不同。

### 2.4 浪潮海岳（Inspur Haiyue）— 国内最接近 13RP 的工业软件

| 维度 | 评估 |
|------|------|
| **定位** | AI 原生智能 ERP，三层架构（AI 数智底座 + AI 原生软件 + AI 智能体） |
| **核心实力** | 100+ 场景智能体，模拟仿真引擎 + 知识工程优化引擎 |

**与 13RP 的重叠：**

| 能力 | 描述 | 对比 13RP |
|------|------|----------|
| **数字孪生与仿真** | 模拟仿真引擎，业务数字孪生全景还原 | ≈ 6-7RP |
| **多约束智能仿真优化** | 从"数据描述→诊断→分析→模拟→运筹优化→决策"全层级 | ≈ 7-8RP |
| **智能体集群** | 智能排产、预测性维护等 100+ Agent | ≈ 5RP + 部分 9RP 概念 |
| **落地案例** | 特变电工数字孪生工厂（上万点位设备连接） | 工业级验证 |

**关键差异：**
- 浪潮海岳的"仿真"侧重已知约束下的优化排程，不做多宇宙并行推演
- 不做博弈对抗（不模拟竞争对手行为）
- 不做 CEO 愿景→目标的 LLM 拆解（11-13RP）

**对 13RP 的威胁等级：🟡 中** — 国内最接近的竞品，如果浪潮向上延伸加博弈/愿景层，可能形成竞争。但浪潮本质仍是"更好的 ERP"，与 13RP 的架构哲学不同。

## 五、关键发现：13RP 的差异化定位空白

### 5.1 市场空白图

```
                    高 ← 决策自主度 → 低
                    ┌─────────────────────────┐
              高    │  o9      Cosmo Tech     │  ← 有仿真+优化，无博弈
             ↑      │  ToolsGroup             │
           仿       │                         │
           真   ────┼─────────────────────────┤
           保       │          ★ 13RP         │  ← 仿真+寻优+博弈+愿景，四合一
           真       │  (空白地带)              │
           度       │                         │
             ↓      │  AnyLogic   Palantir    │  ← 有仿真/数据，无寻优博弈
              低    │  NVIDIA     SAP         │
                    └─────────────────────────┘
```

### 5.2 13RP 的五个差异化维度

| 维度 | 市场现状 | 13RP 的差异化 |
|------|---------|-------------|
| **1. 多宇宙并行** | 所有竞品都是"单一模型"推演 | 10RP：100 个平行世界同时跑，筛出胜率 TOP3 |
| **2. 博弈对抗** | 无竞品内置博弈模块（学界论文多，产品化零） | 9RP：AI 模拟对手/政府/国际组织的反应 |
| **3. 愿景→目标拆解** | o9/Cosmo 有 LLM 交互，但无愿景拆解 | 13RP：CEO 一句话 → 系统拆解为目标-约束-里程碑 |
| **4. 可证伪性内建** | 无竞品内置"失效条件"输出 | 每个方案必附带"什么条件下会失效" |
| **5. 降维输出** | 大部分产品输出报告/建议，不输出可执行指令 | 精确到"今天下午 3 点的 5 条指令" |

### 5.3 学界的独立验证信号

以下 2025-2026 年的学术动态独立验证了 13RP 方向的前沿性：

| 信号 | 来源 | 含义 |
|------|------|------|
| "仿真优先原则"（LOM-action） | arXiv 2026 | 13RP 的"虚实闭环"被学术界独立提出 |
| 认知数字供应链孪生（CDSCT） | Expert Systems w/ Applications 2025 | 数字孪生 + 深度学习 + 恢复规划 = 13RP 的 6-8RP 概念 |
| 数字孪生 + DDPG 强化学习自适应 | Applied Sciences 2025 | IoT + DT + RL 实时自适应 = 13RP 的 6-10RP 闭环 |
| 超图演化博弈用于工业互联网 | Systems 2026 | 博弈论在供应链决策中的应用被学术验证 |
| 世界模型数字孪生的安全风险（RCL） | AAAI 2026 | 数字孪生从监控→自主决策的安全框架需求被提出 |

## 六、竞争态势总结与战略建议

### 6.1 SWOT 分析

| 优势 (Strengths) | 劣势 (Weaknesses) |
|------------------|-------------------|
| 五维差异化（多宇宙/博弈/愿景拆解/可证伪/降维输出）独一无二 | 零产品、零客户、零收入 |
| 架构设计有前瞻性，学术独立验证 | 团队仅 6 人（P0），资源极度有限 |
| 三层架构清晰，1-5 层可采购集成节省时间 | 全链路打通的技术复杂度极高 |

| 机会 (Opportunities) | 威胁 (Threats) |
|----------------------|---------------|
| 92% 企业数字孪生卡在可视化阶段，能做"预判决策"是蓝海 | 浪潮/用友/金蝶等国产 ERP 巨头向上延伸 |
| 全球数字供应链孪生 2032 年 27 亿美元，CAGR 6.4% | NVIDIA Cosmos 等物理仿真平台下沉做应用 |
| 中国市场中小制造企业 SaaS 接受度 67%，轻量化机会大 | o9/Cosmo Tech 等专业厂商补上博弈/Agent 短板 |

### 6.2 战略建议

1. **12 个月窗口期**：当前无直接竞品，但巨头（浪潮/NVIDIA/o9）可能在 12-18 个月内从不同方向进入。P0-P2 必须在这个窗口内完成核心技术验证。

2. **护城河在 6-10 层**：1-5 层是集成工程（无壁垒），11-13 层是 LLM 调用（跟随生态），真正的壁垒在自研的推演引擎 + NSGA-III 多目标寻优 + 多智能体博弈对抗。

3. **与竞品的互补关系**：
   - **AnyLogic** → 13RP 的仿真引擎（集成，非竞争）
   - **Gurobi** → 13RP 的求解器底层（集成，非竞争）
   - **NVIDIA Omniverse** → 13RP 的高保真渲染底座（互补）
   - **Palantir Foundry** → 13RP 的概念参考（本体论建模），非竞品

4. **优先参考产品**（按参考价值排序）：
   - 🥇 **Cosmo Tech** — 仿真+优化一体化的最佳范本，小公司做到 Gartner 认可
   - 🥈 **o9 Solutions** — 知识图谱驱动的数字孪生架构，年创数亿美元客户价值
   - 🥉 **ToolsGroup Decion™** — Agentic AI + 概率决策的理念最接近 13RP 2026 年叙事
   - 🏅 **浪潮海岳** — 国内工业软件中 AI 仿真最成熟，需持续关注其博弈/Agent 方向
