# 13RP — 博宇宙十三维决策操作系统

> **"不是 ERP 的升级版，是决策方式的代际革命。"**

传统 ERP 告诉企业"现在有什么"，13RP 告诉企业"如果发生 X 该怎么办、这么做会怎样、最优解是什么、今天下午 3 点该干什么"。

---

| 维度 | 状态 |

## 架构速览

```
愿景驱动层 (11-13RP) → 定方向：可插拔大模型 Agent 体系        [合作调用 LLM]
平行模拟层 (6-10RP)  → 算路径：自研孪生·推演·寻优·博弈·迭代    [核心护城河]
物理现实层 (1-5RP)   → 数据底座：ERP（选型待定，赤龙 ERP 等开源方案仅作参考）+ 周边集成    [开源 + 采购]
```

## 一分钟启动（编码开始后可用）

```bash
# 克隆仓库
git clone <repo-url> 13RP-Demo && cd 13RP-Demo

# 一键启动（需要 Docker）
docker compose up -d

# 浏览器访问（macOS 用 open，Windows 用 start）
open http://localhost:5173        # macOS
start http://localhost:5173       # Windows
```

### 本地开发

| 组件 | 命令 | 默认端口 |
|------|------|:---:|
| 后端 | `cd backend && ./mvnw spring-boot:run` | `8080` |
| 前端 | `cd frontend && pnpm install && pnpm dev` | `5173` |

> 详细环境搭建见 [`Demo技术方案与开发手册.md`](03_P0阶段_MVP/Demo技术方案与开发手册.md) 第六章。
